# 🌱 DreamFlow

### Plan Your Tasks. Track Your Dreams.

DreamFlow is a beautiful two-in-one productivity web app that combines everyday task management with long-term goal tracking — helping you stay organized today while working toward what matters most.

---

## ✨ Features

- 📝 *Smart To-Do List* — task management with priorities, due dates, search and filters
- 🎯 *Dream List Goal Tracker* — set long-term goals and visually track your progress
- 🔍 *Search & Filter* — quickly find tasks by priority, date, or keyword
- 📊 *Progress Visualization* — see how far you've come on your biggest goals
